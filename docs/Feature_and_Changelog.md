## 产品介绍
一款为本地图片增加水印文字的 iOS App，支持自定义文字水印并能轻松导出处理后的图片。本应用主要特点是简单易用、本地化运行，保证用户数据隐私安全。

## 功能说明
1. 图片上传：支持从本地相册选择图片，一次仅能处理一张
2. 水印自定义：
   - 水印文字内容："仅用于申请 xx 信用卡使用，他用无效"（默认选项）
   - 文字大小调节，提供滑块让用户在预设范围（如 10pt - 40pt）内调整字号
   - 文字透明度调节，支持 20%-100% 范围
   - 文字颜色选择（白色、黑色、红色、蓝色）
3. 实时预览：调整水印效果实时显示
4. 图片导出：处理完成后可保存到相册

## 使用流程
1. 用户打开 App，进入 **首页**。
2. 在首页点击 **添加按钮**，从相册选择图片。
3. App 自动跳转至 **编辑水印页面**，图片加载默认水印并实时预览。
4. 在编辑水印页面 **自定义水印** 文字、大小、透明度、颜色，预览实时更新。
5. 点击编辑水印页面右上角的 **保存** 按钮，将处理后的图片导出到相册。
6. 如需返回，可点击编辑水印页面左上角的 **返回按钮** (< SafeMark) 回到首页。
7. 在首页点击右上角的 **设置 icon**，进入 **设置页面** 查看相关信息或进行反馈。

## 技术要点
1. 图片处理和水印渲染
   - 使用 Core Graphics 绘制水印
   - 根据图片分辨率动态调整水印网格密度
2. 用户偏好设置存储
   - 保存最近使用的水印设置
3. 本地化处理
   - 所有图片处理在本地完成，不需要网络连接
   - 不上传用户图片数据，保护隐私
4. 简洁直观的用户界面
   - 操作步骤简单明了
   - 符合 iOS 设计规范，使用 iOS 标准蓝色(#007AFF)作为主色调
   - 响应式设计，适配不同设备尺寸
